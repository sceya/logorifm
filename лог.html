📖 Определение логарифма и ОДЗ

🔹 Что такое логарифм? +

Логарифм числа b по основанию a — это показатель степени...

Логарифм числа b по основанию a — это показатель степени, в которую нужно возвести a, чтобы получить b.

logₐ(b) = c ⇔ aᶜ = b

Где:

  • a — основание логарифма (a > 0, a ≠ 1)
  • b — аргумент логарифма (b > 0)
  • c — значение логарифма

Примеры:

  • log₂(8) = 3, потому что 2³ = 8
  • log₃(81) = 4, потому что 3⁴ = 81
  • log₅(1/25) = -2, потому что 5⁻² = 1/25

🛡️ Область допустимых значений (ОДЗ) +

Аргумент логарифма всегда строго больше нуля, основание положительно и не равно единице.

ОДЗ для логарифма logₐ(f(x)):

  • f(x) > 0 — аргумент логарифма должен быть строго положительным
  • a > 0 — основание должно быть положительным
  • a ≠ 1 — основание не может равняться единице

Почему это важно?

Логарифм отрицательного числа не существует в действительных числах. Логарифм нуля также не определён.

📐 Основные свойства логарифмов

➕ Сложение и вычитание +

logₐ(x·y) = logₐx + logₐy
logₐ(x/y) = logₐx − logₐy

Логарифм произведения:

logₐ(x·y) = logₐx + logₐy

Логарифм частного:

logₐ(x/y) = logₐx − logₐy

📈 Степень +

logₐ(xᵖ) = p·logₐx
logₐ(√x) = ½·logₐx
logₐ(xᵖ) = p·logₐx

Частные случаи:

  • logₐ(√x) = ½·logₐx
  • logₐ(1/x) = −logₐx

🔄 Переход к новому основанию +

logₐb = logᵦb / logᵦa
logₐb = 1 / log₈a
logₐb = logᵦb / logᵦa

Следствия:

  • logₐb = 1 / log₈a
  • logₐⁿb = (1/n)·logₐb

🧪 Разбор типовых уравнений
Тип 1: Простейшее уравнение
log₂(x+1) = 3
Нажмите для подробного решения

log₂(x+1) = 3 ⇔ x+1 = 2³ = 8 ⇒ x = 7

ОДЗ: x+1>0 ⇒ x>−1. Ответ: x = 7 ✓

Тип 2: Равенство логарифмов
log₃(2x−4) = log₃(x+1)
Нажмите для подробного решения

2x−4 = x+1 ⇒ x = 5

Проверка ОДЗ: 2·5−4=6>0, 5+1=6>0 ✓

Тип 3: Сумма логарифмов
log₂(x) + log₂(x−2) = 3
Нажмите для подробного решения

log₂(x(x−2)) = 3 ⇒ x²−2x = 8 ⇒ x=4 или x=−2

ОДЗ: x>0 и x−2>0 ⇒ x>2. Ответ: x=4

🔄 Методы решения

① Приведение к одному основанию+

Привести все логарифмы к одному основанию, затем потенцировать.

Алгоритм: привести к общему основанию → упростить → потенцировать → проверить ОДЗ.

② Замена переменной+

t = logₐ(f(x)), решаем уравнение относительно t.

Пример: log₃²(x) − 5·log₃(x) + 6 = 0 → t²−5t+6=0 → x=9 или x=27.

③ Логарифмирование+

Логарифмируем обе части, если переменная в показателе.

Пример: 2ˣ = 10 → log₂(2ˣ) = log₂(10) → x = log₂(10).

④ Графический метод+

Строим графики, ищем точки пересечения.

Полезен для уравнений вида log₂(x) = 5 − x.

📈 Продвинутые темы

🔹 Логарифмические неравенства+

При 0 < a < 1 знак неравенства меняется.

logₐ(f) > logₐ(g): если a>1, то f>g; если 0

🔹 Переменное основание+

logₓ(2x+3) = 2: ОДЗ x>0, x≠1, 2x+3>0.

Решение: x² = 2x+3 ⇒ x=3 (x=−1 посторонний).

🔹 Системы с логарифмами+

Решаются потенцированием или заменой.

Пример: log₂(xy)=3, x+y=6 ⇒ xy=8, x+y=6 ⇒ x=2,y=4.

🔹 Производная логарифма+

(logₐx)' = 1/(x·ln a), (ln x)' = 1/x.

Используется для исследования функций и построения графиков.
